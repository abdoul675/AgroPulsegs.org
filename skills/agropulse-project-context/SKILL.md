# Contexte AgroPulse

Dans le workspace AgroPulse courant, lire `docs/PROJECT_CONTEXT.md` et `docs/README.md`, puis les sections pertinentes des documents référencés. Si le workspace n’est pas identifié, le localiser avant de déduire l’état du projet. Les chemins relatifs sont relatifs à sa racine, pas au dossier de ce skill.

Les demandes récentes du porteur prévalent sur les propositions historiques. Distinguer : accord du porteur, accord de Mme Hélène Nichy, recommandation, configuration présente et fonction vérifiée. Une validation générique ne fournit pas les dates, destinataires ou responsables encore absents.

Pour un état d’avancement, préciser le lot courant, le livrable disponible, les décisions restantes et la prochaine action concrète. Ne pas confondre maquette HTML et site de production. Ne reprendre ni les microservices ni les règles de Talent-Job sans source AgroPulse.

Après un changement de décision dans le périmètre demandé, mettre à jour le document concerné et le contexte si nécessaire, sans modifier les sources historiques. Signaler toute contradiction sans inventer sa résolution.
